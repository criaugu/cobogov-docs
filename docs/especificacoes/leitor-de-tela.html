Leitor de tela

Para cada componente do DS gov.br: o papel, de onde vem o nome acessível, os estados, o que o leitor de tela deve anunciar, o teclado e o que o desenvolvimento precisa garantir. É a base da aba Leitor de tela da Documentação de acessibilidade do CoboGov, que usa a versão do DS escolhida nos Dados do projeto.
