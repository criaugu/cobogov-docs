Skip Link

Versões do DSV3 e V4
Papel (role)link
Elemento HTML<a href="#id-do-destino">
Classe / componentebr-skiplink
OrigemVeio da documentação do DS gov.br, completada onde faltava.

Documentação oficial: gov.br/ds · next-ds.

Nome acessível​

O texto do link diz o destino ("Ir para o conteúdo principal"). Os atalhos numerados vêm com a sequência visível. Exemplo: Ir para o conteúdo principal.

O que é anunciado​

Esperado conforme o padrão (WAI-ARIA APG): {nome}, link

Comportamento esperado, não a fala exata: NVDA, JAWS, VoiceOver e TalkBack variam. No plugin, cada elemento tem um campo para o resultado do teste com leitor de tela real.

Estados​

Em foco (fica visível)​

  • No código: sem ARIA: o link só aparece ao receber foco
  • Acrescenta ao anúncio: {nome}, link

Teclado​

TeclaO que faz
TabAvança para o próximo item ou sai do componente no último item
Shift+TabRetrocede para o item anterior ou sai do componente no primeiro item
EnterAtiva o link e move o foco para o elemento de destino
Fonte: documentação do DS gov.br (V4).

Para o desenvolvimento​

br-skiplink (V3) / <br-skip-link> (V4, id "skip-link"). Deve ser o primeiro item focável da página, apontar para âncoras que existem e o destino precisa poder receber foco (tabindex="-1" quando não for focável). No exemplo V3 os links estão em role="menubar"/"menuitem"; a V4 usa links simples, sem marcação extra.

Diferenças entre V3 e V4​

  • V3: notaCodigo: br-skiplink: o exemplo do core usa nav role="menubar" com role="menuitem" e accesskey 1 a 4; o texto "(1/4)" e a etiqueta numerada são aria-hidden.
  • V4: notaCodigo: <br-skip-link>: cada item é um link com nome descritivo; não requer marcação de acessibilidade adicional.

Fontes​

  • DS gov.br V4 · next-ds — Skip Link, acessibilidade
  • DS gov.br V3 · @govbr-ds/core — Skiplink (documentação e código de exemplo)
  • WCAG · WCAG 2.2 — 2.4.1 Ignorar blocos
  • eMAG 3.1 · eMAG 3.1 — Recomendação 1.5 (fornecer âncoras para ir direto a um bloco de conteúdo)
