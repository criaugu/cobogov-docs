Tab

A confirmar

Nenhuma fonte cobre tudo deste componente: o ponto em aberto está na seção "Para o desenvolvimento". Se você testou na implementação, conte o que viu nos comentários.

Versões do DSV3
Papel (role)tablist, tab e tabpanel
Elemento HTML<ul role="tablist"><li role="presentation"><button role="tab" aria-selected aria-controls> + <div role="tabpanel" aria-labelledby>
Classe / componentebr-tab
OrigemA documentação do DS não cobre o essencial: completado pela curadoria com o padrão do W3C (WAI-ARIA APG) e o eMAG.

Documentação oficial: gov.br/ds.

Nome acessível​

O texto da aba; aba só com ícone leva aria-label (o exemplo do core usa); cada painel é nomeado pela aba. Exemplo: Documentos.

O que é anunciado​

Esperado conforme o padrão (WAI-ARIA APG): {nome}, guia, {posicao} de {total}{estado}

Comportamento esperado, não a fala exata: NVDA, JAWS, VoiceOver e TalkBack variam. No plugin, cada elemento tem um campo para o resultado do teste com leitor de tela real.

Estados​

Selecionada​

  • No código: aria-selected="true|false"
  • Acrescenta ao anúncio: selecionada

Desabilitado​

  • No código: aria-disabled="true"
  • Acrescenta ao anúncio: indisponível

Teclado​

TeclaO que faz
TabEntra na lista de abas (só a aba ativa é parada) e depois no painel
← / →Movem entre as abas
Home / EndPrimeira / última aba
Enter ou EspaçoAtiva a aba, se a ativação não for automática
Fonte: curadoria (WAI-ARIA APG).

Para o desenvolvimento​

br-tab (V3). O código de exemplo do core mostra <button> dentro de tab-item com aria-label nas abas de ícone; os papéis tab/tablist/tabpanel e aria-selected não aparecem no código e dependem do JavaScript do core. A confirmar no navegador: se são aplicados e se as setas funcionam.

Fontes​

  • DS gov.br V3 · @govbr-ds/core — Tab (documentação e código de exemplo)
  • W3C WAI-ARIA APG · WAI-ARIA APG — Tabs Pattern
  • WCAG · WCAG 2.2 — 4.1.2 Nome, função, valor
