Avatar

Versões do DSV3 e V4
Papel (role)img (informativo) · link ou button (interativo) · presentation (decorativo)
Elemento HTML<img alt> ou <span> com iniciais; <a>/<button> quando interativo
Classe / componentebr-avatar
OrigemVeio da documentação do DS gov.br, completada onde faltava.

Documentação oficial: gov.br/ds · next-ds.

Nome acessível​

O nome da pessoa (alt da foto ou texto das iniciais com o nome completo). Avatar que abre menu ou perfil leva o nome da ação. Exemplo: Foto de perfil de Maria Souza.

O que é anunciado​

Esperado conforme o padrão (WAI-ARIA APG): {nome}, imagem · {nome}, botão{estado}

Comportamento esperado, não a fala exata: NVDA, JAWS, VoiceOver e TalkBack variam. No plugin, cada elemento tem um campo para o resultado do teste com leitor de tela real.

Estados​

Abre menu​

  • No código: aria-haspopup="menu" e aria-expanded="true|false" no gatilho
  • Acrescenta ao anúncio: menu, recolhido / expandido

Decorativo (nome já está ao lado)​

  • No código: alt="" ou aria-hidden="true"
  • Acrescenta ao anúncio: (ignorado)

Teclado​

TeclaO que faz
TabNavega para o item seguinte
Shift+TabNavega para o item anterior
EnterAtiva o Avatar
EspaçoAtiva o Avatar
Fonte: documentação do DS gov.br (V4).

Para o desenvolvimento​

br-avatar (V3) / <br-avatar> (V4). Avatar estático só informa: sem foco. Avatar que abre menu é um <button> com nome de ação ("Abrir menu do usuário"). No V3 o menu do avatar usa role="menu" e role="menuitem" nos itens.

Diferenças entre V3 e V4​

  • V3: notaCodigo: br-avatar; no exemplo do core o menu associado usa role="menu"/"menuitem" e o gatilho tem aria-labelledby.
  • V4: notaCodigo: <br-avatar>; teclado: Tab/Shift+Tab, Enter e Espaço quando interativo.

Fontes​

  • DS gov.br V4 · next-ds — Avatar, acessibilidade
  • DS gov.br V3 · @govbr-ds/core — Avatar (documentação e código de exemplo)
  • eMAG 3.1 · eMAG 3.1 — Recomendação 3.6 (alternativa em texto para as imagens do sítio)
  • W3C WAI-ARIA APG · WAI-ARIA APG — Menu Button Pattern
